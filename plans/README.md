  MED-HIGH risk to scroll choreography. Do after 001 provides a safety net.
- **Font pipeline duplication** — Astro `Font` API (2 families × 5 weights)
  AND four `@fontsource/ubuntu` imports in `HomeLayout.astro`; a stale build
  showed 83 font preloads / 2.3 MB woff2. S effort, high payoff.
- **Oversized public images** — `public/coffee-brew.webp` 4.5 MB,
  `fire.webp` 900 KB (rendered at ~56 px), `images/bg.webp` 876 KB on every
  page. M effort, mechanical.

  `src/pages/mn/`; already drifted (`mn/index.astro` lacks the loading
  fallback slot). Fix via dynamic `[...lang]` routes, M effort/MED risk.
- **Merge `Layout.astro` + `HomeLayout.astro`** (~95% identical, drifted).

  English; `BEANS` in `consts.ts` is English-only; `RoastedBeans.tsx` and
  `MobileMenu.tsx` hardcode English strings. Content-bound, S–M.
- **Dead code removal** — `src/lib/animations.ts` (174 lines),

## Findings considered and rejected

- "Both Mux player packages are unused" (security agent) — **wrong**:
  `@mux/mux-player-react` is imported in `Hero.tsx` and `Since.tsx`. Only the
  bare `@mux/mux-player` direct dep is redundant (plan 003 removes just that).
- "GROQ interpolation is an injection vulnerability" — not exploitable today
  (value is a compile-time enum); downgraded to a pattern fix inside plan 005.
- `/admin` studio exposure as an auth hole — it is not one (Sanity login +
  CORS gate it); reduced to headers hardening in plan 002 and a backlog note.
- E2E/visual-regression suite and 80% coverage targets — disproportionate for
  a 13-route landing page; build gate + targeted unit tests suffice.
- Rewriting git history to purge the leaked `middlewareSecret` — the secret
  regenerates per build and is superseded at next deploy; untracking (plan
  002) is sufficient.
- The ~70 remaining `pnpm audit` high/critical advisories — transitive,
  build-time-only packages under the `sanity` studio toolchain; not reachable
  from the deployed site. Re-triage only if the studio split happens.
